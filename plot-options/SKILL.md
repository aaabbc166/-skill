# 剧情推演（plot-options）

路径基准：文中所有文件路径均相对于项目根目录。

输入：本章上下文简报 + 细纲

动作：基于上下文推演本章 2~3 个剧情走向，每个标注：

- 走向描述（3 句内）

- 与细纲的吻合度

- 触发的伏笔 / 冲突点（注明伏笔编号）

- 风险（是否偏离人物性格或能力体系）

输出：走向清单 + 选定结论（含选定理由）

约束：由智能体按细纲吻合度与风险自主选定推荐走向并直接落笔，不再停等确认；主人可随时叫停或改选
