# 文章生成（chapter-drafting）

路径基准：文中所有文件路径均相对于项目根目录。

输入：主人确认的剧情走向 + 上下文简报

动作：按 规则/文风规则.md 与 规则/用词习惯.md 生成正文，目标字数 [3000~5000]

要求：

- 开头承接上一章结尾

- 每 800~1000 字一个钩子

- 不引入未登记的新设定

- 新伏笔必须先分配编号（F+卷号+两位序号）并登记

输出：章节正文
